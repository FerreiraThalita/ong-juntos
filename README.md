# Juntos — Projeto acadêmico de ONG

Site com três páginas usando HTML5 semântico, CSS3 e JavaScript.

- index.html — página inicial
- projetos.html — iniciativas solidárias
- cadastro.html — formulário de engajamento
- css/style.css — estilos e responsividade
- js/script.js — máscaras de CPF, telefone e CEP + validação de CPF
